# Login-Register-Online-Form

Уеб приложение за регистрация и вход, написано на Java без framework, с MySQL база.

## Изисквания

- Java 21 или по-нова
- MySQL 8

## Настройка

1. Създай базата и таблицата:
   ```
   mysql -u root -p < schema.sql
   ```
2. Задай паролата за MySQL като променлива на средата:
   ```
   setx DB_PASS "твоята_парола"
   ```
   След това отвори нов терминал.

## Стартиране

```
run.cmd
```

Отвори http://localhost:8080

## Тестове

```
test.cmd
```

Отчетът за покритието е в `coverage/index.html`. Тестовете за базата се пропускат, ако `DB_PASS` не е зададен.
