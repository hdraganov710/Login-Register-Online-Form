# Login-Register-Online-Form

Уеб приложение за регистрация и вход, написано на чиста Java (без framework) с MySQL база.

## Функционалности

- Регистрация с валидация на имейл, имена и парола
- CAPTCHA, генерирана от приложението (без външна услуга)
- Вход и изход (сесия с бисквитка)
- Страница за промяна на имената и паролата
- Паролите се пазят като PBKDF2 хеш със сол
- Unit тестове с JUnit 5 и отчет за покритието с JaCoCo

## Изисквания

- Java 21 или по-нова
- MySQL 8

## Настройка

1. Създай базата и таблицата:
   ```
   mysql -u root -p < schema.sql
   ```
2. Задай паролата за MySQL като променлива на средата:
   ```
   setx DB_PASS "твоята_парола"
   ```
   След това отвори нов терминал.

## Стартиране

```
run.cmd
```

Отвори http://localhost:8080

## Тестове

```
test.cmd
```

Отчетът за покритието е в `coverage/index.html`. Тестовете за базата се пропускат, ако `DB_PASS` не е зададен.

## Структура

| Файл | Какво прави |
|---|---|
| `Main.java` | Стартира сървъра |
| `WebServer.java` | Страниците и обработката на заявките |
| `UserService.java` | Регистрация, вход, промяна на профила |
| `Validator.java` | Проверка на имейл, имена и парола |
| `PasswordHasher.java` | Сол и хеширане на паролата |
| `Captcha.java` | Генериране на CAPTCHA картинка |
| `User.java` | Модел на потребител |
| `UserRepository.java` | Интерфейс за достъп до потребителите |
| `MySqlUserRepository.java` | Работа с MySQL |
| `Database.java` | Връзка с базата |
